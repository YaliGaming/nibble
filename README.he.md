# Nibble

**חיית מחמד לשולחן העבודה, בשביל Claude Code.** היא צפה מעל שאר החלונות, מראה מה הסשנים שלך ב־Claude Code עושים, ומודיעה כשאחד מהם צריך אותך.

<p align="center"><img src="docs/demo.gif" width="250" alt="החיה בזמן שסשן עובד, מבקש הרשאה ומסיים"></p>

[English](README.md)

> Nibble הוא פרויקט קהילתי. הוא לא נוצר על ידי Anthropic, לא מאושר על ידה ואינו קשור אליה. ההשראה: ה־Pets באפליקציית ChatGPT.

## מה היא עושה

- **מצב אחד לכל הסשנים**, בטרמינל ובאפליקציית Claude: עובד, מחכה לך, מוכן או נתקע. בועה מעל החיה אומרת מה Claude עושה עכשיו ("עורך את auth.ts").
- **אישור הרשאות מהחיה.** כש־Claude מבקש להריץ משהו, מופיעים על הבועה "אישור" ו"דחייה". אפשר עדיין לענות ב־Claude עצמו; התשובה הראשונה קובעת.
- **צ׳אט מהיר.** שאלה ל־Claude Code מכל מקום (`Ctrl + Alt + P`) בלי לפתוח חלון. התשובה חוזרת לחיה.
- **רשימת פעילות** של הסשנים, עם ההודעה האחרונה והתשובה.
- **`/pet`** בכל סשן של Claude Code מדליק או מכבה את החיה, בלי לעלות טוקנים.
- **נפתחת ונסגרת עם Claude.** כשהיא דולקת, היא מופיעה כשסשן נפתח ונעלמת כמה שניות אחרי שהאחרון נסגר. היא לא עולה עם Windows.
- **חיות משלך.** ארבע מובנות. אפשר לתאר חדשה ("דרקון סגול") ו־Claude מצייר אותה, או לייבא חיה שמישהו שיתף.
- עברית (מימין לשמאל) ואנגלית, לפי שפת המערכת. שפה נוספת היא קובץ JSON אחד.
- צליל והתראת Windows כשסשן צריך אותך, מסיים או נכשל. שניהם כבויים כברירת מחדל.

![החיה בכל מצב](docs/states.png)

## דרישות

- Windows 10 או 11. macOS ו־Linux עדיין לא נתמכות (ראו [מגבלות](#מגבלות)).
- [Claude Code](https://claude.com/claude-code) בגרסה עדכנית. Nibble נבדק עם 2.1.292; בגרסאות ישנות בהרבה חסרים חלק מה־hooks.

## התקנה

1. מורידים את `Nibble-Setup-x.y.z.exe` מה[גרסה האחרונה](../../releases/latest) ומריצים.
2. לוחצים על החיה, ואז **חיבור**.

קובץ ההתקנה לא חתום דיגיטלית, ולכן בפעם הראשונה Windows SmartScreen מציג "Windows protected your PC". בוחרים **More info** ואז **Run anyway**. מי שמעדיף שלא, יכול להריץ מהקוד (למטה); זה אותו קוד.

לא צריך להתקין שום דבר נוסף. האפליקציה מביאה עותק משלה של Node.js בשביל הסקריפטים הקטנים ש־Claude Code מריץ.

### הרצה מהקוד

צריך [Node.js](https://nodejs.org/) 22 ומעלה.

```bash
npm install
```

```bash
npm start
```

ב־Windows אפשר גם ללחוץ פעמיים על `Nibble.cmd`.

### מצבים

| מצב | משמעות |
| --- | --- |
| עובד | סשן באמצע עבודה. הבועה אומרת על מה. |
| מחכה לך | Claude מחכה להרשאה, לתשובה או להחלטה. |
| מוכן | סשן סיים ועוד לא ראית את התוצאה. |
| נתקע | סשן נכשל או נתקל בשגיאת API. |

כשיש כמה סשנים, החיה מראה את הדחוף ביותר: מחכה לך, אחריו נתקע, מוכן, ועובד. אחרי עשר דקות שקטות היא נרדמת.

### אישור הרשאות

כשסשן מבקש הרשאה, מופיעים על הבועה שני כפתורים: אישור ודחייה. אותם כפתורים נמצאים גם בעמוד של הסשן בפאנל.

כברירת מחדל זה פועל בסשנים של אפליקציית Claude ובצ׳אט המהיר, ושם זה נבדק: החלון של Claude נשאר פתוח לצד הכפתורים של החיה, והתשובה הראשונה קובעת. סשנים בטרמינל רגיל לא מושפעים, אלא אם מוסיפים `"approvalsEverywhere": true` לקובץ `~/.nibble-pet/config.json`; השילוב הזה לא נבדק, אז זה ניסוי. אפשר לכבות את כל התכונה בהגדרות.

### צ׳אט מהיר

כותבים שאלה ולוחצים Enter. כברירת מחדל היא רצה ברקע (`claude -p`) והתשובה מופיעה בפאנל, שם אפשר להמשיך את השיחה או לעבור לטרמינל. אם Claude צריך הרשאה, החיה שואלת אותך. בהגדרות אפשר לבחור שהצ׳אט המהיר ייפתח בטרמינל.

בלי תיקייה, הצ׳אט רץ בתיקייה ריקה (`~/.nibble-pet/quick-chat`). אפשר לבחור תיקיית פרויקט מהרשימה שליד כפתור השליחה.

### `/pet`

אחרי חיבור, מקלידים `/pet` בכל סשן של Claude Code. אם החיה דולקת היא נכבית: האפליקציה נסגרת ולא חוזרת לבד. אם היא כבויה היא נדלקת.

hook של Claude Code עונה לפקודה לפני שהיא מגיעה למודל. בגלל זה היא בחינם, ובגלל זה התשובה מופיעה תחת הכותרת "UserPromptExpansion operation blocked by hook". זו לא שגיאה; ככה Claude Code מציג פקודה ש־hook טיפל בה.

### חיות

Ember,‏ Mochi,‏ Byte ו־Boo מובנות, ו"מיני" מציג רק את הכפתורים.

- **בקיעה:** בהגדרות כותבים תיאור ולוחצים "בקיעה". Claude מצייר אותה בפיקסלים. גם `/hatch-pet דרקון סגול` בסשן של Claude Code עושה את זה.
- **שיתוף:** חיה היא קובץ JSON קטן אחד. "ייצוא החיה…" שומר אותו, "ייבוא חיה…" טוען אחד.

החיה מכבדת את ההגדרה "הפחתת תנועה" של Windows: כל מצב הופך לתמונה אחת.

## החיבור ל־Claude Code

גם בלי חיבור החיה רואה אם סשן עסוק, מחכה או סיים, כי היא קוראת את רשימת הסשנים ש־Claude Code מנהל ב־`~/.claude/sessions`.

**חיבור** מוסיף [hooks](https://code.claude.com/docs/en/hooks) לקובץ `~/.claude/settings.json`. איתם החיה יודעת גם מה Claude עושה, מציגה את התשובה שלו, מזהה כישלונות, ויכולה להציע אישור ודחייה.

- לפני כל שינוי הקובץ מועתק אל `~/.nibble-pet/backups`.
- נוספות רק רשומות שמריצות את שני הסקריפטים של Nibble. כל השאר בקובץ נשאר כמו שהיה.
- **ניתוק** מסיר בדיוק את הרשומות האלה, וגם הסרת האפליקציה עושה את זה.
- נוספות שתי פקודות ל־`~/.claude/skills`:‏ `/pet` ו־`/hatch-pet`.

## פרטיות

הכול נשאר במחשב שלך. ל־Nibble אין טלמטריה, אין חשבון ואין בדיקת עדכונים, והוא לא שולח שום דבר לרשת. (צ׳אט מהיר מריץ את ה־Claude Code שלך, שמדבר עם Anthropic כמו תמיד.)

מה שה־hook כותב, שורה לכל אירוע, אל `~/.nibble-pet/events/<session>.jsonl`:

- השעה, סוג האירוע, מזהה הסשן, תיקיית העבודה שלו, והאם הוא רץ בטרמינל או באפליקציה;
- כותרת הסשן ו־400 התווים הראשונים של כל הודעה שלך;
- לכל הפעלת כלי: שם הכלי ותווית קצרה (תיאור הפקודה או 100 התווים הראשונים שלה, שם קובץ בלי התיקייה, ביטוי חיפוש, שם אתר);
- ההודעה האחרונה של Claude בכל תור, עד 4,000 תווים;
- הודעות התראה ושגיאה.

יומן של סשן נמחק שבוע אחרי האירוע האחרון שלו. בהגדרות:

- **שמירת הטקסט של ההודעות והתשובות**: כשמכבים, נרשמים רק סוגי האירועים, בלי שום טקסט מהרשימה למעלה. החיה עדיין מראה מצבים, אבל לא מה Claude עושה ומה הוא ענה.
- **מחיקת ההיסטוריה**: מוחקת את כל היומנים עכשיו.

| נתיב | תוכן |
| --- | --- |
| `~/.nibble-pet/config.json` | ההעדפות שלך. |
| `~/.nibble-pet/events/` | יומני הסשנים שתוארו למעלה. |
| `~/.nibble-pet/pets/` | חיות שיצרת או ייבאת. |
| `~/.nibble-pet/backups/` | עותקים של `settings.json` מלפני כל שינוי. |
| `~/.nibble-pet/hook.js`,‏ `pet.js` | שני הסקריפטים ש־Claude Code מריץ. |
| `~/.claude/skills/pet`,‏ `hatch-pet` | שתי הפקודות. |

## הסרה

מסירים את Nibble דרך הגדרות Windows, אפליקציות. ההסרה גם מוציאה את ה־hooks ואת הפקודות מ־Claude Code. הנתונים נשארים ב־`~/.nibble-pet`; מוחקים את התיקייה אם לא רוצים אותם.

בהרצה מהקוד: "ניתוק" בהגדרות, "כיבוי החיה", ומחיקת שתי התיקיות.

## מגבלות

- **רק Windows בינתיים.** הקוד נמנע מממשקים ייחודיים ל־Windows איפה שאפשר, אבל התנהגות החלון, הפעלת האפליקציה וההתקנה נבנו ונבדקו רק על Windows.
- **רשימת הסשנים היא לא ממשק רשמי.** Claude Code לא מתעד את `~/.claude/sessions`, ולכן גרסה עתידית עשויה לשנות אותה. Nibble מתייחס לכל מה שיש בה כאופציונלי, ועם ה־hooks מחוברים הוא לא תלוי בה לדברים החיוניים. hooks הם ממשק מתועד ויציב.
- **קובץ ההתקנה לא חתום**, ומכאן האזהרה של SmartScreen.
- **לא למחשבים נעולים.** אם הארגון מנהל את ההגדרות של Claude Code ולא מרשה hooks של המשתמש, ל"חיבור" אין השפעה.
- סשנים שרצים במחשב אחר (Claude Code בדפדפן, סשנים מרוחקים) לא מוצגים.
